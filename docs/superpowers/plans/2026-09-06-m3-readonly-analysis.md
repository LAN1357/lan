# M3 只读经营分析实施记录

日期：2026-09-06。依据：`docs/superpowers/specs/2026-09-06-m3-readonly-analysis-design.md`。

## 已实现

- 独立只读 SQLite reader：固定路径、`mode=ro`、`PRAGMA query_only=ON`，只查询 `months` 与 `closes`；缺库和旧结构不创建、不迁移。
- 当前与历史版本语义：当前版本重开即阻断，历史版本必须显式查询，跨月核算规则不兼容即阻断。
- 确定性汇总、筛选、完整范围比率、排名、期间比较和严格守恒的利润科目桥。
- 单场利润、SKU直接贡献、关账分配与人工修改的窄证据视图；同月版本差异比较。
- 指标规则字典、四类固定事实诊断规则；事实与BP待核查问题分开，不生成健康评分。
- 费用与SKU单位成本条件测算：固定单一关账版本，最多20项明确假设，沿用M1纯函数，基准逐分复核，结果仅在内存产生。
- 独立 FastMCP stdio 服务，精确注册八个 `workbench_` 工具，并声明只读、非破坏、幂等和非开放世界注解。
- 新只读角色说明和接入文档。旧 `src/server.py`、旧MCP工具及M2工作台流程未接入或改写。

## 验证

- `pytest -q`：129项通过。
- 合成账例：两场月合计、汇总利润率、分页排名、利润桥、版本差异、证据视图、费用测算和SKU逐笔成本测算通过。
- 真实本地工作台库烟测：八个工具均可调用；不存在的V2明确返回 `VERSION_NOT_FOUND`；测算前后数据库文件SHA-256一致。
- MCP工具目录验证：只有八个工具，全部 `readOnlyHint=true`、`destructiveHint=false`、`openWorldHint=false`，输入中无路径或SQL参数。
- Codex CLI 0.148.0 已注册用户级 `livecommerce-m3-readonly` 并显示启用；Claude Code 2.1.168 已注册相同用户级服务，健康检查显示连接成功。旧 `livecommerce-roi-agent → src/server.py` 配置已从两个客户端移除。
- 使用与客户端配置完全一致的绝对命令和环境，从 `/tmp` 启动标准MCP ClientSession：初始化成功、发现八个工具，关账目录调用返回成功。
